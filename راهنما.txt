    راهنمای اجرای برنامه - حسابداری فروشگاه
================================================================

مشکل:
-----
وقتی روی index.html کلیک می‌کنید، برنامه باز نمی‌شود چون
نیاز به سرور محلی دارد.

راه حل ساده:
------------

روش 1: کلیک روی start.bat (ساده‌ترین - بدون نصب)
--------------------------------------------------
1. فایل "start.bat" را پیدا کنید
2. روی آن دابل‌کلیک کنید
3. مرورگر به صورت خودکار باز می‌شود
4. تمام!

این فایل از PowerShell استفاده می‌کند که در ویندوز نصب است.


روش 2: با Python
-----------------
1. Python را از اینجا دانلود کنید:
   https://www.python.org/downloads/

2. موقع نصب، تیک "Add Python to PATH" را بزنید

3. کامپیوتر را ریستارت کنید

4. Command Prompt را باز کنید و بنویسید:

   cd dist
   python -m http.server 8000

5. در مرورگر باز کنید:
   http://localhost:8000


================================================================
    خلاصه سریع
================================================================

مرورگر در آدرس زیر باز می‌شود:
http://localhost:8000
