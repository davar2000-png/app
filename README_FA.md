# 📥 راهنمای دانلود و نصب (خیلی ساده)

## 🎯 مراحل کامل (قدم به قدم)

### مرحله ۱: دانلود فایل‌ها از GitHub

1. مرورگر خود را باز کنید (Chrome, Firefox, Edge)

2. به این آدرس بروید:
   ```
   https://github.com/davar2000-png/store-appnew
   ```

3. در صفحه GitHub، یک دکمه سبز رنگ **"Code"** می‌بینید

4. روی دکمه **"Code"** کلیک کنید

5. یک منو باز می‌شود. روی **"Download ZIP"** کلیک کنید

6. فایل ZIP دانلود می‌شود (مثلاً: `store-appnew-main.zip`)

---

### مرحله ۲: استخراج فایل‌ها

1. به پوشه **Downloads** بروید

2. فایل `store-appnew-main.zip` را پیدا کنید

3. روی فایل **راست‌کلیک** کنید

4. گزینه **"Extract All..."** را انتخاب کنید

5. یک پنجره باز می‌شود:
   - مسیر را به `C:\Users\TechnoKala\` تغییر دهید
   - روی **"Extract"** کلیک کنید

6. صبر کنید تا فایل‌ها استخراج شوند

7. یک پوشه جدید ایجاد می‌شود: `store-appnew-main`

---

### مرحله ۳: نصب Node.js

1. به این آدرس بروید:
   ```
   https://nodejs.org/
   ```

2. روی دکمه سبز بزرگ **"LTS"** کلیک کنید

3. فایل نصب دانلود می‌شود

4. روی فایل نصب **دابل‌کلیک** کنید

5. مراحل نصب را دنبال کنید:
   - Next
   - Accept (قبول قوانین)
   - Next
   - Next
   - Install
   - Finish

6. **کامپیوتر را ریستارت کنید** (مهم!)

---

### مرحله ۴: اجرای برنامه

1. **CMD** را باز کنید:
   - کلید **Windows + R** را بزنید
   - تایپ کنید: `cmd`
   - Enter را بزنید

2. به پوشه پروژه بروید:
   ```bash
   cd C:\Users\TechnoKala\store-appnew-main
   ```

3. دستور زیر را اجرا کنید:
   ```bash
   start.bat
   ```

4. صبر کنید:
   - ابتدا وابستگی‌ها نصب می‌شوند (۱-۲ دقیقه)
   - سپس پروژه build می‌شود
   - سپس سرور اجرا می‌شود
   - مرورگر به صورت خودکار باز می‌شود

5. برنامه در آدرس `http://localhost:8000` باز می‌شود

## ❓ سوالات متداول

### سوال: فایل ZIP کجاست؟
**جواب:** در پوشه Downloads کامپیوتر شما

### سوال: Node.js نصب نشد؟
**جواب:** کامپیوتر را ریستارت کنید و دوباره تلاش کنید

### سوال: start.bat کار نمی‌کند؟
**جواب:** 
1. مطمئن شوید در مسیر درست هستید
2. دستور `dir` را بزنید تا فایل‌ها را ببینید
3. باید فایل `start.bat` را ببینید

### سوال: مرورگر باز نشد؟
**جواب:** 
1. صبر کنید تا سرور کاملاً اجرا شود
2. مرورگر را به صورت دستی باز کنید
3. آدرس `http://localhost:8000` را وارد کنید

## 📞 اگر مشکل داشتید

1. مطمئن شوید Node.js نصب است:
   ```bash
   node --version
   ```
   باید نسخه Node.js را نشان دهد

2. مطمئن شوید در مسیر درست هستید:
   ```bash
   dir
   ```
   باید فایل `start.bat` را ببینید

3. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```

4. دوباره اجرا کنید:
   ```bash
   start.bat
   ```
