# 🏪 سیستم حسابداری فروشگاه - نسخه کامل

یک سیستم حسابداری کامل و حرفه‌ای برای مدیریت فروشگاه‌ها با قابلیت‌های پیشرفته.

## ✨ ویژگی‌های اصلی

### 📊 داشبورد
- نمایش آمار لحظه‌ای
- فروش امروز
- تعداد کالاها و اشخاص
- بدهی کل

### 🛒 فاکتور خرید
- **تاریخ شمسی** خودکار
- **شماره فاکتور** قابل ویرایش (شماره سفارش خرید)
- **وضعیت پیش‌فرض**: دریافت نشده
- **جستجوی فروشنده** بر اساس نام و تلفن
- **افزودن فروشنده جدید** در لحظه
- **جستجوی کالا** بر اساس نام و برند
- **تسویه حساب** با روش‌های مختلف:
  - 💵 نقدی
  - 📝 چک (با شماره چک)
  - 🏦 حواله (با شماره حواله)
- **محاسبات خودکار** جمع کل، پرداخت شده، باقیمانده

### 📋 لیست فاکتورها
- نمایش تمام فاکتورها
- **ثبت دریافت** برای فاکتورهای خرید
- تغییر وضعیت: دریافت شده / جزئی / دریافت نشده
- نمایش تاریخ دریافت
- نمایش وضعیت تسویه

### ⚙️ تنظیمات
- **پشتیبان‌گیری** کامل از تمام داده‌ها
- **بازیابی** از فایل پشتیبان
- ذخیره‌سازی خودکار در localStorage

## 🎯 قابلیت‌های کلیدی

### ✅ تاریخ شمسی
- تمام تاریخ‌ها به صورت شمسی
- فرمت: `۲۵ آذر ۱۴۰۳`
- تاریخ امروز خودکار

### ✅ جستجوی هوشمند
- جستجوی فروشنده بر اساس نام و تلفن
- جستجوی کالا بر اساس نام و برند
- فیلتر زنده نتایج

### ✅ مدیریت وضعیت دریافت
- پیش‌فرض: دریافت نشده
- قابل تغییر از لیست فاکتورها
- ثبت تاریخ دریافت

### ✅ تسویه حساب ترکیبی
- پشتیبانی از چندین روش پرداخت
- ثبت توضیحات برای هر پرداخت
- محاسبه خودکار باقیمانده

### ✅ ذخیره‌سازی محلی
- تمام داده‌ها در مرورگر ذخیره می‌شوند
- بدون نیاز به سرور
- کاملاً آفلاین

### ✅ پشتیبان‌گیری
- دانلود فایل JSON از تمام داده‌ها
- بازیابی از فایل
- انتقال آسان بین دستگاه‌ها

## 🚀 نحوه استفاده

### شروع کار
```bash
# روی start.bat دابل‌کلیک کنید
# یا
npm run dev
```

### ثبت فاکتور خرید
1. به تب **"🛒 فاکتور خرید"** بروید
2. تاریخ شمسی خودکار نمایش داده می‌شود
3. شماره فاکتور را وارد کنید (شماره سفارش خرید)
4. وضعیت دریافت: "دریافت نشده ⏳"
5. فروشنده را جستجو یا اضافه کنید
6. کالا را جستجو و اضافه کنید
7. تسویه‌ها را ثبت کنید
8. روی **"✓ ثبت فاکتور خرید"** کلیک کنید

### ثبت دریافت
1. به تب **"📋 لیست فاکتورها"** بروید
2. فاکتور مورد نظر را پیدا کنید
3. روی **"✓ دریافت شد"** یا **"⏳ جزئی"** کلیک کنید
4. وضعیت و تاریخ دریافت به‌روزرسانی می‌شود

### پشتیبان‌گیری
1. روی دکمه **"💾 پشتیبان"** در هدر کلیک کنید
2. فایل JSON دانلود می‌شود
3. در جای امن ذخیره کنید

### بازیابی
1. روی دکمه **"📥 بازیابی"** در هدر کلیک کنید
2. فایل JSON را انتخاب کنید
3. داده‌ها بازیابی می‌شوند

## 📁 ساختار فایل‌ها

```
src/
├── App.tsx              # کامپوننت اصلی (برنامه کامل)
├── types.ts             # تعریف تایپ‌ها
├── utils.ts             # توابع کمکی (تاریخ شمسی، فرمت اعداد)
├── index.css            # استایل‌ها
└── main.tsx             # نقطه ورود
```

- **فارسی** کامل با فونت وزیرمتن
- **راست‌چین** (RTL)

## 💡 نکات مهم

### تاریخ شمسی
- تمام تاریخ‌ها به صورت شمسی نمایش داده می‌شوند
- تبدیل خودکار از میلادی به شمسی
- فرمت خوانا: `۲۵ آذر ۱۴۰۳`

### شماره فاکتور
- به صورت خودکار تولید می‌شود
- قابل ویرایش است
- می‌توانید شماره سفارش خرید را وارد کنید
- فرمت: `K-14030915-001`

### وضعیت دریافت
- پیش‌فرض: دریافت نشده
- پس از ثبت فاکتور، از لیست فاکتورها قابل تغییر است
- تاریخ دریافت خودکار ثبت می‌شود

### جستجو
- جستجوی فروشنده: نام یا تلفن
- جستجوی کالا: نام یا برند
- فیلتر زنده نتایج

### تسویه حساب
- پشتیبانی از نقدی، چک، حواله
- امکان ثبت چندین تسویه
- توضیحات برای هر تسویه (شماره چک، حواله)
- محاسبه خودکار باقیمانده

## 🎯 مثال‌های کاربردی

### مثال ۱: خرید از دیجی‌کالا
1. شماره فاکتور: `DK-987654321`
2. فروشنده: دیجی‌کالا
3. کالا: گوشی سامسونگ - ۲ عدد
4. تسویه: حواله - ۸۰,۰۰۰,۰۰۰ تومان
5. وضعیت: دریافت نشده
6. بعد از دریافت: تغییر به "دریافت شده"

### مثال ۲: خرید حضوری
1. شماره فاکتور: `سفارش-۱۲۳۴۵`
2. فروشنده: فروشگاه احمدی
3. کالا: لپ‌تاپ ایسوس - ۱ عدد
4. تسویه: نقدی - ۵۰,۰۰۰,۰۰۰ تومان + چک - ۳۰,۰۰۰,۰۰۰ تومان
5. وضعیت: دریافت شده
