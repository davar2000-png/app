# 🏪 تکنوکالا - سیستم حسابداری فروشگاه

سیستم حسابداری حرفه‌ای و کامل برای مدیریت فروشگاه خرید و فروش نقد و اقساط.

## ✨ ویژگی‌های کامل

### 🏠 داشبورد
- فروش و خرید امروز
- سود کل و بدهی کل
- تعداد کالاها، اشخاص، سریال‌ها
- ارزش انبار
- هشدار چک‌های معوق
- هشدار کالاهای کم‌موجود
- هشدار اقساط معوق

### 🏭 مدیریت کالا و انبار
- ثبت کالا با سلسله‌مراتب: گروه → برند → مدل → رنگ/رم/حافظه
- کد خودکار برای هر کالا
- مدیریت گروه‌ها (گوشی، لپ‌تاپ، کنسول، پرینتر، متفرقه)
- مدیریت برندها (Apple, Samsung, Xiaomi, HP, Dell, ASUS, ...)
- مدیریت مدل‌ها
- مدیریت رنگ‌ها با color picker
- کنترل موجودی (حداقل موجودی، نقطه سفارش)
- اجازه موجودی منفی (قابل تنظیم)
- قابلیت سریال‌دار

### 📲 مدیریت سریال موبایل
- ثبت سریال با IMEI
- پیگیری وضعیت سریال (موجود/فروش رفته)
- جستجوی سریال
- محاسبه سود بر اساس سریال
- جلوگیری از ثبت سریال تکراری

### 📊 کاردکس انبار
- کاردکس تعدادی
- کاردکس ریالی
- ورود/خروج/برگشت
- مانده تعدادی و ریالی
- فیلتر بر اساس کالا

### 👥 مدیریت اشخاص
- 5 نوع شخص: مشتری، تأمین‌کننده، ضامن، کارمند، سایر
- اطلاعات کامل: نام، موبایل، تلفن، کد ملی، شغل، شهر، آدرس، کارت بانکی
- بارگذاری مدارک (کارت ملی، قرارداد و...)
- مشاهده مدارک
- جستجوی پیشرفته
- فیلتر بر اساس نوع
- حذف منطقی (No Physical Delete)

### 🛒 فاکتور خرید
- انتخاب تأمین‌کننده
- افزودن چندین کالا
- انتخاب سریال برای کالاهای سریال‌دار
- افزایش خودکار موجودی
- پرداخت نقدی و اقساطی
- ثبت در کاردکس

### 💰 فاکتور فروش
- انتخاب مشتری
- فروش نقدی و اقساطی
- اقساط 3 تا 24 ماه
- محاسبه خودکار اقساط
- تخفیف
- محاسبه سود هر کالا
- کاهش خودکار موجودی
- انتخاب سریال
- کنترل هوشمند:
  - هشدار قیمت کمتر از خرید (رنگ صورتی)
  - هشدار موجودی ناکافی (رنگ زرد)
  - تأیید قبل از ثبت

### 📄 پیش‌فاکتور
- ثبت پیش‌فاکتور
- تبدیل به فاکتور فروش

### 🔄 برگشت از خرید/فروش
- برگشت کامل فاکتور
- بازگشت موجودی
- بازگشت سریال
- ثبت فاکتور برگشتی

### 📋 لیست فاکتورها
- فیلتر خرید/فروش/پیش‌فاکتور
- جستجو
- نمایش اطلاعات کامل

### 📝 مدیریت چک‌ها
- چک دریافتی و پرداختی
- شماره چک، بانک، مبلغ، صادرکننده
- تاریخ سررسید
- هشدار چک‌های معوق
- حذف منطقی

### 💳 مدیریت اقساط
- لیست تمام اقساط
- نمایش اقساط معوق
- پرداخت قسط با یک کلیک
- محاسبه مبلغ معوق

### 🏦 بانک‌ها
- ثبت حساب‌های بانکی
- موجودی اولیه

### 📊 گزارش‌ها
- خلاصه مالی (فروش، خرید، سود)
- سود سریال‌دار
- وضعیت انبار
- ارزش انبار

### 📜 ردیابی تغییرات (Audit Trail)
- ثبت تمام عملیات مهم
- CREATE, UPDATE, DELETE, CANCEL, RETURN, PAYMENT
- جستجو در لاگ‌ها
- نمایش تاریخ و جزئیات

### 📥 ورود از اکسل
- ورود اشخاص از فایل اکسل
- پیش‌نمایش داده‌ها
- اعتبارسنجی
- نمایش خطاها
- پشتیبانی از .xlsx و .xls

### ⚙️ تنظیمات
- پشتیبان‌گیری (Export JSON)
- بازیابی (Import JSON)
- آمار سیستم

## 🚀 نحوه استفاده

### روش ۱: استفاده مستقیم
1. فایل `dist/index.html` را در مرورگر باز کنید
2. برنامه آماده استفاده است! ✅

### روش ۲: اجرای محلی
```bash
npm install
npm run dev
```

### روش ۳: ساخت نسخه تولید
```bash
npm run build
```

## 💾 پشتیبان‌گیری

داده‌ها در مرورگر (localStorage) ذخیره می‌شوند.

### پشتیبان‌گیری:
1. به تب **⚙️ تنظیمات** بروید
2. روی **💾 پشتیبان‌گیری** کلیک کنید
3. فایل JSON دانلود می‌شود

### بازیابی:
1. به تب **⚙️ تنظیمات** بروید
2. روی **📥 بازیابی** کلیک کنید
3. فایل JSON را انتخاب کنید

## 📊 ساختار داده‌ها

### Person (شخص)
```typescript
{
  id, type, name, familyName, nationalId, job,
  employeeId, phone, mobile, bankCard, address,
  city, image, notes, creditor, debtor,
  documents: PersonDocument[], isDeleted, createdAt
}
```

### Product (کالا)
```typescript
{
  id, code, name, categoryId, brandId, modelId,
  color, ram, storage, buyPrice, sellPrice,
  stock, minStock, reorderPoint, allowNegativeStock,
  hasSerial, isDeleted, createdAt
}
```

### SerialItem (سریال)
```typescript
{
  id, productId, serialNumber, imei1, imei2,
  purchasePrice, purchaseInvoiceId, status,
  saleInvoiceId, soldDate, soldPrice, profit, createdAt
}
```

### Invoice (فاکتور)
```typescript
{
  id, invoiceNumber, type, personId, items,
  total, discount, paid, remaining, paymentType,
  installments, status, returnInvoiceId,
  description, date, createdAt
}
```
