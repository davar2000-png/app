# 🏪 نرم‌افزار حسابداری فروشگاه

یک نرم‌افزار حسابداری کامل و حرفه‌ای برای مدیریت فروشگاه خرید و فروش نقد و اقساط گوشی موبایل، لپ‌تاپ، کنسول بازی، پرینتر و سایر کالاها.

## ✨ ویژگی‌های اصلی

### 🏠 داشبورد
- نمایش فروش و خرید امروز
- تعداد کل کالاها
- بدهی کل مشتریان
- هشدار کالاهای با موجودی کم

### 🏭 مدیریت کالا و انبار

#### ثبت کالا
- **کد خودکار** برای هر کالا
- **سلسله‌مراتبی**: گروه → برند → مدل → رنگ/رم/حافظه
- **مدیریت موجودی**: موجودی فعلی، حداقل موجودی، نقطه سفارش
- **شماره سریال**: پشتیبانی از چندین شماره سریال
- **کنترل موجودی منفی**: قابل تنظیم برای هر کالا
- **قیمت خرید و فروش**: محاسبه خودکار سود

#### گروه‌های کالایی پیش‌فرض
- 📱 گوشی موبایل
- 💻 لپ‌تاپ
- 🎮 کنسول بازی
- 🖨️ پرینتر
- 📦 متفرقه

#### برندهای پیش‌فرض
- **گوشی**: Apple, Samsung, Xiaomi
- **لپ‌تاپ**: HP, Dell, ASUS, Lenovo
- **کنسول**: PS5
- **پرینتر**: HP, Canon, Brother

#### مدیریت کامل
- ✅ **افزودن** گروه، برند، مدل، رنگ جدید
- ✅ **ویرایش** همه موارد
- ✅ **حذف** با حذف سلسله‌مراتبی
- ✅ **رنگ‌های سفارشی** با color picker

- شماره تلفن
- کد ملی
- شغل
- شهر
- آدرس
- یادداشت

#### جستجوی پیشرفته
- جستجو بر اساس نام، تلفن، کد ملی، شهر

#### مدیریت کامل
- ✅ افزودن شخص جدید
- ✅ ویرایش اطلاعات
- ✅ حذف شخص

### 🛒 فاکتور خرید

#### ویژگی‌ها
- انتخاب تأمین‌کننده
- افزودن چندین کالا
- قیمت خرید سفارشی
- افزایش خودکار موجودی
- ثبت توضیحات

### 💰 فاکتور فروش

#### ویژگی‌ها
- انتخاب مشتری
- افزودن چندین کالا
- **فروش نقدی**: پرداخت کامل
- **فروش اقساطی**:

## 🚀 نصب و اجرا

### روش ۱: استفاده مستقیم (ساده‌ترین)

1. فایل `dist/index.html` را در مرورگر باز کنید
2. برنامه آماده استفاده است! ✅

### روش ۲: اجرای محلی (برای توسعه)

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# برنامه در آدرس http://localhost:5173 اجرا می‌شود
```

### روش ۳: ساخت نسخه تولید

```bash
# Build برای تولید
npm run build

# فایل‌ها در پوشه dist قرار می‌گیرند
```

### روش ۴: آپلود روی وب

#### Vercel (پیشنهادی - رایگان)
```bash
npm install -g vercel
vercel
```

#### Netlify (رایگان)
```bash
npm install -g netlify-cli
netlify deploy --prod --dir=dist
```

#### GitHub Pages (رایگان)
1. کد را در GitHub قرار دهید
2. به Settings → Pages بروید
3. Branch را روی `gh-pages` و پوشه `/dist` قرار دهید

## 💾 پشتیبان‌گیری

### چرا باید پشتیبان‌گیری کنید؟
- داده‌ها در مرورگر ذخیره می‌شوند
- اگر کش مرورگر پاک شود، داده‌ها حذف می‌شوند
- برای انتقال به کامپیوتر دیگر

### چگونه پشتیبان‌گیری کنید؟
1. در هدر برنامه، دکمه **"💾 پشتیبان"** را بزنید
2. فایل JSON دانلود می‌شود
3. آن را در جای امن ذخیره کنید

### چگونه بازیابی کنید؟
1. دکمه **"📥 بازیابی"** را بزنید
2. فایل JSON را انتخاب کنید
3. داده‌ها بازیابی می‌شوند ✅

## 📱 استفاده در موبایل

1. فایل `dist/index.html` را به موبایل منتقل کنید
2. با مرورگر موبایل باز کنید
3. می‌توانید آن را به Home Screen اضافه کنید

## 📋 راهنمای استفاده

### ۱. ثبت کالای جدید

1. به تب **"🏭 کالا و انبار"** بروید
2. روی **"➕ ثبت کالا"** کلیک کنید
3. گروه کالا را انتخاب کنید (مثلاً: گوشی موبایل)
4. برند را انتخاب کنید (مثلاً: Samsung)
5. مدل را انتخاب کنید (مثلاً: Galaxy S24)
6. رنگ، رم، حافظه را انتخاب کنید
7. قیمت خرید و فروش را وارد کنید
8. موجودی، حداقل موجودی، نقطه سفارش را تنظیم کنید
9. شماره سریال‌ها را وارد کنید (هر خط یک شماره)
10. دکمه **"✓ ثبت کالا"** را بزنید

### ۲. ثبت شخص جدید

1. به تب **"👥 اشخاص"** بروید
2. اطلاعات شخص را وارد کنید
3. دکمه **"✓ ثبت شخص"** را بزنید

### ۳. ثبت فاکتور فروش نقدی

1. به تب **"💰 فاکتور فروش"** بروید
2. مشتری را انتخاب کنید
3. نوع پرداخت را **"💵 نقدی"** انتخاب کنید
4. کالاها را اضافه کنید
5. دکمه **"✓ ثبت فاکتور"** را بزنید

### ۴. ثبت فاکتور فروش اقساطی

1. به تب **"💰 فاکتور فروش"** بروید
2. مشتری را انتخاب کنید
3. نوع پرداخت را **"💳 اقساطی"** انتخاب کنید
4. پیش‌پرداخت را وارد کنید
5. تعداد اقساط را انتخاب کنید (3 تا 24 ماه)
6. کالاها را اضافه کنید
7. دکمه **"✓ ثبت فاکتور"** را بزنید

### ۵. مدیریت گروه‌ها، برندها، مدل‌ها، رنگ‌ها

1. به تب **"🏭 کالا و انبار"** بروید
2. روی تب مورد نظر کلیک کنید:
   - **📁 گروه‌ها**: مدیریت گروه‌های کالا
   - **🏷️ برندها**: مدیریت برندها
   - **📱 مدل‌ها**: مدیریت مدل‌ها
   - **🎨 رنگ‌ها**: مدیریت رنگ‌ها
3. برای افزودن: فرم بالا را پر کنید و **"➕"** را بزنید
4. برای ویرایش: روی **"✏️ ویرایش"** کلیک کنید
5. برای حذف: روی **"🗑️ حذف"** کلیک کنید

## 📊 ساختار داده‌ها

### Product (کالا)
```typescript
{
  id: string
  code: string              // کد خودکار
  name: string              // نام کامل
  categoryId: string        // گروه کالا
  brandId: string           // برند
  modelId: string           // مدل
  color?: string            // رنگ
  ram?: string              // رم
  storage?: string          // حافظه
  buyPrice: number          // قیمت خرید
  sellPrice: number         // قیمت فروش
  stock: number             // موجودی
  minStock: number          // حداقل موجودی
  reorderPoint: number      // نقطه سفارش
  allowNegativeStock: boolean // اجازه موجودی منفی
  serialNumbers: string[]   // شماره سریال‌ها
  description?: string      // توضیحات
  createdAt: string         // تاریخ ثبت
}
```

### Customer (شخص)
```typescript
{
  id: string
  name: string
  phone: string
  address?: string
  nationalId?: string
  job?: string
  city?: string
  creditor?: number
  debtor?: number
  image?: string
  notes?: string
  createdAt: string
}
```

### Invoice (فاکتور)
```typescript
{
  id: string
  invoiceNumber: string
  type: 'purchase' | 'sale'
  customerId: string
  items: InvoiceItem[]
  total: number
  paid: number
  remaining: number
  paymentType: 'cash' | 'installment'
  installments?: Installment[]
  date: string
  description?: string
}
```
