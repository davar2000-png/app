# 🏪 تکنوکالا - سیستم حسابداری فروشگاه

سیستم حسابداری حرفه‌ای و کامل برای مدیریت فروشگاه خرید و فروش نقد و اقساط.

## ✨ ویژگی‌ها

### 🏠 داشبورد
- فروش و خرید امروز
- سود کل و بدهی کل
- تعداد کالاها و اشخاص
- ارزش انبار
- هشدار چک‌های معوق
- هشدار کالاهای کم‌موجود
- هشدار اقساط معوق

### 🏭 مدیریت کالا و انبار
- ثبت کالا با سلسله‌مراتب: گروه → برند → مدل → رنگ/رم/حافظه
- کد خودکار برای هر کالا
- مدیریت گروه‌ها (گوشی، لپ‌تاپ، کنسول، پرینتر، متفرقه)
- مدیریت برندها (Apple, Samsung, Xiaomi, HP, Dell, ASUS, ...)
- مدیریت مدل‌ها
- مدیریت رنگ‌ها با color picker
- کنترل موجودی (حداقل موجودی، نقطه سفارش)
- اجازه موجودی منفی (قابل تنظیم)

### 👥 مدیریت اشخاص
- انواع شخص: مشتری، تأمین‌کننده، ضامن، کارمند، سایر
- اطلاعات کامل: نام، موبایل، تلفن، کد ملی، شغل، شهر، آدرس، کارت بانکی
- جستجوی پیشرفته
- فیلتر بر اساس نوع
- ویرایش و حذف

### 🛒 فاکتور خرید
- انتخاب تأمین‌کننده
- افزودن چندین کالا
- افزایش خودکار موجودی
- محاسبه خودکار

### 💰 فاکتور فروش
- انتخاب مشتری
- فروش نقدی و اقساطی
- اقساط 3 تا 24 ماه
- محاسبه خودکار اقساط
- تخفیف
- محاسبه سود هر کالا
- کاهش خودکار موجودی

### 📋 لیست فاکتورها
- فیلتر بر اساس نوع (خرید/فروش)
- جستجو
- نمایش اطلاعات کامل

### 📝 مدیریت چک‌ها
- چک دریافتی و پرداختی
- شماره چک، بانک، مبلغ، صادرکننده
- تاریخ سررسید
- هشدار چک‌های معوق

### 💳 مدیریت اقساط
- لیست تمام اقساط
- نمایش اقساط معوق
- پرداخت قسط با یک کلیک
- محاسبه مبلغ معوق

### 🏦 بانک‌ها
- ثبت حساب‌های بانکی
- موجودی اولیه

### 📊 گزارش‌ها
- خلاصه مالی (فروش، خرید، سود)
- وضعیت چک‌ها
- وضعیت انبار

### ⚙️ تنظیمات
- پشتیبان‌گیری (Export JSON)
- بازیابی (Import JSON)
- آمار سیستم

## 🚀 نحوه استفاده

### روش ۱: استفاده مستقیم
1. فایل `dist/index.html` را در مرورگر باز کنید
2. برنامه آماده استفاده است! ✅

### روش ۲: اجرای محلی
```bash
npm install
npm run dev
```

### روش ۳: ساخت نسخه تولید
```bash
npm run build
```

## 💾 پشتیبان‌گیری

داده‌ها در مرورگر (localStorage) ذخیره می‌شوند.

### پشتیبان‌گیری:
1. به تب **⚙️ تنظیمات** بروید
2. روی **💾 پشتیبان‌گیری** کلیک کنید
3. فایل JSON دانلود می‌شود

### بازیابی:
1. به تب **⚙️ تنظیمات** بروید
2. روی **📥 بازیابی** کلیک کنید
3. فایل JSON را انتخاب کنید

## 🛠️ تکنولوژی‌ها

- **TypeScript** - تایپ‌سیف
- **Vite** - بیلد سریع
- **Tailwind CSS** - استایل‌دهی
- **localStorage** - ذخیره‌سازی محلی

## 📊 ساختار داده‌ها

### Person (شخص)
```typescript
{
  id, type, name, familyName, nationalId, job,
  employeeId, phone, mobile, bankCard, address,
  city, image, notes, creditor, debtor, createdAt
}
```

### Product (کالا)
```typescript
{
  id, code, name, categoryId, brandId, modelId,
  color, ram, storage, buyPrice, sellPrice,
  stock, minStock, reorderPoint, allowNegativeStock,
  description, createdAt
}
```

### Invoice (فاکتور)
```typescript
{
  id, invoiceNumber, type, personId, items,
  total, discount, paid, remaining, paymentType,
  installments, status, description, date, createdAt
}
```

### Cheque (چک)
```typescript
{
  id, chequeNumber, bankName, amount, issuerName,
  issuerNationalId, dueDate, type, status,
  relatedInvoiceId, relatedPersonId, description, createdAt
}
```
