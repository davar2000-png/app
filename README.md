## 🚀 نحوه استفاده

### روش 1: استفاده مستقیم
1. فایل `dist/index.html` را در مرورگر باز کنید
2. برنامه آماده استفاده است! ✅

### روش 2: اجرای محلی
```bash
npm install
npm run dev
```

### روش 3: ساخت نسخه تولید
```bash
npm run build
```

## 💾 پشتیبان‌گیری

داده‌ها در مرورگر (localStorage) ذخیره می‌شوند.

### پشتیبان‌گیری:
1. به تب **⚙️ تنظیمات** بروید
2. روی **💾 پشتیبان‌گیری** کلیک کنید
3. فایل JSON دانلود می‌شود

### بازیابی:
1. به تب **⚙️ تنظیمات** بروید
2. روی **📥 بازیابی** کلیک کنید
3. فایل JSON را انتخاب کنید

## 📊 ساختار داده‌ها

### Person (شخص)
```typescript
{
  id, type, groupId, name, familyName, nationalId, job,
  employeeId, phone, mobile, bankCard, address, city,
  image, notes, creditor, debtor,
  documents: PersonDocument[],
  guarantor?: Guarantor,
  isDeleted, createdAt
}
```

### Guarantor (ضامن)
```typescript
{
  id, name, mobile, phone, nationalId, address, job,
  image, documents: PersonDocument[]
}
```

### Product (کالا)
```typescript
{
  id, code, name, categoryId, brandId, modelId,
  color, ram, storage, serialNumber,
  buyPrice, sellPrice, stock, minStock, reorderPoint,
  allowNegativeStock, isDeleted, createdAt
}
```
