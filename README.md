# 🏪 سیستم حسابداری فروشگاه

یک سیستم حسابداری ساده و کاربردی برای مدیریت فروشگاه.

## ✨ ویژگی‌ها

- 📊 داشبورد با آمار کلی
- 📦 مدیریت محصولات
- 👥 مدیریت مشتریان
- 🧾 ایجاد فاکتور (نقدی و اقساطی)
- 💾 ذخیره خودکار در مرورگر

## 🚀 نحوه اجرا (خیلی ساده!)

### مرحله ۱: نصب Node.js
اگر Node.js نصب ندارید، از اینجا دانلود کنید:
https://nodejs.org/

### مرحله ۲: اجرای برنامه
فقط کافیست فایل `start.bat` را اجرا کنید!

```bash
start.bat
```

این فایل به صورت خودکار:
1. وابستگی‌ها را نصب می‌کند (اگر نصب نشده)
2. پروژه را build می‌کند
3. سرور را شروع می‌کند
4. مرورگر را باز می‌کند

برنامه در آدرس `http://localhost:3000` باز می‌شود.

## 📋 استفاده

### داشبورد
- مشاهده آمار کلی فروش
- مشاهده آخرین فاکتورها

### محصولات
- افزودن محصول جدید
- مشاهده لیست محصولات

### مشتریان
- افزودن مشتری جدید
- مشاهده لیست مشتریان

### فاکتورها
- ایجاد فاکتور جدید
- انتخاب مشتری و محصولات
- انتخاب نوع پرداخت (نقدی/اقساطی)

## 💾 ذخیره‌سازی

تمام داده‌ها به صورت خودکار در مرورگر شما ذخیره می‌شوند.

## 🛠️ تکنولوژی‌ها

- React
- TypeScript
- Vite
- Tailwind CSS
